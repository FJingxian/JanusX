# JanusX v2.0.0 Release Notes

Compared with v1.0.27, v2.0.0 adds native PGEN support and new analysis workflows, simplifies the GWAS model surface, and includes broad statistical, memory, and cross-platform build fixes.

## Highlights

- **PLINK 2 input:** Added native Rust streaming support for PGEN/PVAR/PSAM through `-pfile`, with genotype-format conversion support in `gformat`.
- **Cis/trans pair scans:** Added `jx ct` for phase-independent D×D scans of nearby variant pairs, with bounded input, whitening, and output batches.
- **FastPop population genetics:** Added WC/Hudson FST and XP-CLR workflows under `fastpop`; the standalone `jx fst` command has been retired.
- **GARFIELD interaction scans:** Added the Max6 screening and GRM-INT scoring workflow, including adaptive low-rank screening and a default minimum cell count of `max(10, ceil(0.01 × Neff))`.
- **Genomic selection:** Added BayesR, PLS, and KRR workflows, expanded Bayesian diagnostics and controls, and made saved model artifacts self-contained for prediction.
- **Streaming performance:** Fused QC into supported BED scan paths, added positioned reads for sequential scans, and moved high-volume result formatting/writing behind bounded workers.

## Statistical and correctness fixes

- Made GWAS fixed-effect handling use effective design rank so redundant covariates do not reduce residual degrees of freedom unnecessarily.
- Corrected SparseLMM approximate and exact paths for phenotype-scale invariance and redundant fixed effects; aligned scan behavior and output scales.
- Corrected HE/PCG variance and PVE reporting in genomic selection, and added the missing null-PVE standard error for FvLMM.
- Improved dense REML variance fitting and null-model handling; corrected FarmCPU stage updates and checked its QTN results against rMVP.
- Aligned native LD pruning with PLINK founder semantics, preserved SNP IDs and merge metadata, and fixed PGEN conversions and compressed HMP output.
- Fixed phenotype parsing with pandas 3, explicit-threshold highlighting in `postgwas`, and several Windows/macOS build and runtime issues.

## Compatibility changes

- GWAS now uses additive marker coding. Heterozygosity QC statistics and filters, the BIN route, and LMM2 remain available; non-additive association branches have been removed.
- `-splmm` selects the approximate SparseLMM scan and `-splmm-exact` selects the exact scan. The obsolete `-splmm-approx` spelling is not supported.
- `jx fst` is replaced by the FST workflow in `jx fastpop`.
- The standalone `jx benchmark` command has been removed.
- The unused Metal GPU backend has been removed; v2.0.0 analysis workflows use the CPU backends.

## Build and validation

- The [v2.0.0 release workflow](https://github.com/FJingxian/JanusX/actions/runs/41474360133) completed its source-distribution and configured wheel builds for Linux x86_64/aarch64, macOS x86_64/arm64, and Windows x86_64/arm64. The TestPyPI upload job succeeded.
- Production PyPI and Bioconda publication are separate from that workflow run. Install the PyPI package with `python -m pip install janusx==2.0.0` when it is available from the package index.

相较于 v1.0.27，v2.0.0 增加了原生 PGEN 支持和新的分析流程，收敛了 GWAS 模型接口，并修复了多项统计、内存和跨平台构建问题。

## 主要更新

- **PLINK 2 输入：** 新增 Rust 原生 PGEN/PVAR/PSAM 流式读取，可通过 `-pfile` 使用；`gformat` 也支持相关格式转换。
- **cis/trans 位点对扫描：** 新增 `jx ct`，用于邻近位点对的不依赖相位 D×D 扫描，并采用有界读取、白化和输出批次。
- **FastPop 群体遗传：** 将 WC/Hudson FST 和 XP-CLR 流程整合到 `fastpop`，独立的 `jx fst` 命令已移除。
- **GARFIELD 互作扫描：** 新增 Max6 筛选与 GRM-INT 评分流程，并加入自适应低秩筛选；默认最小细胞数为 `max(10, ceil(0.01 × Neff))`。
- **基因组选择：** 新增 BayesR、PLS 和 KRR 流程，扩展贝叶斯诊断与控制参数，并使保存的模型文件可独立用于预测。
- **流式性能：** 在支持的 BED 扫描路径中融合 QC，顺序扫描使用定位读取，并通过有界后台任务处理大批量结果格式化和写盘。

## 统计与正确性修复

- 固定效应处理改用设计矩阵有效秩，避免冗余协变量不必要地降低残差自由度。
- 修复 SparseLMM approximate/exact 路径的表型尺度不变性和冗余固定效应处理，并统一扫描行为及输出尺度。
- 修正基因组选择中 HE/PCG 方差和 PVE 汇报，并补上 FvLMM null PVE 的标准误。
- 改进 dense REML 方差拟合与零模型处理；修正 FarmCPU 阶段更新，并用 rMVP 检查 QTN 结果。
- 使原生 LD pruning 对齐 PLINK founder 语义，保留 SNP ID 与合并元数据，并修复 PGEN 转换及压缩 HMP 输出。
- 修复 pandas 3 下的表型解析、`postgwas` 显式阈值标记，以及多项 Windows/macOS 构建和运行问题。

## 兼容性变更

- GWAS 现在采用加性标记编码。保留杂合度 QC 统计与过滤、BIN 路径和 LMM2；非加性关联分支已移除。
- `-splmm` 表示 SparseLMM approximate 扫描，`-splmm-exact` 表示 exact 扫描；不再支持旧写法 `-splmm-approx`。
- `jx fst` 已由 `jx fastpop` 中的 FST 流程替代。
- 独立的 `jx benchmark` 命令已移除。
- 未使用的 Metal GPU 后端已移除；v2.0.0 的分析流程使用 CPU 后端。

## 构建与验证

- [v2.0.0 发布工作流](https://github.com/FJingxian/JanusX/actions/runs/41474360133) 已完成源码包构建，以及 Linux x86_64/aarch64、macOS x86_64/arm64、Windows x86_64/arm64 的配置构建矩阵；TestPyPI 上传任务成功。
- 正式 PyPI 与 Bioconda 发布由该工作流之外的步骤完成；PyPI 包可用后，可通过 `python -m pip install janusx==2.0.0` 安装。
